# lab

Приложения к публикациям, протоколы и рабочие документы. Все открывается в браузере:

**https://solameer.github.io/lab/**

Автор - Алексей Хардиков. Телеграм-канал "Второе мнение": https://t.me/dr_khardikov

## Что где лежит

Деление по сроку жизни материала, не по теме и не по дате.

| Папка | Что внутри | Жизненный цикл |
|---|---|---|
| `guides/` | Протоколы, методички, чек-листы | Живут и обновляются, на них ссылаются разные публикации |
| `articles/` | Приложения к конкретной статье | Замораживаются после выхода публикации |

Дат в путях нет: хронология живет на витрине, а адрес должен оставаться коротким и не намекать,
что материал просрочен.

## Материалы

- `guides/3d-model-eval/` - протокол кросс-модельного теста "собери 3D-модель". Есть PDF на одном листе.
- `articles/tie-fighter/` - пять интерактивных 3D-моделей истребителя TIE, по одной на каждую ИИ-модель.

## Как это устроено

Каждая страница - самодостаточный HTML-файл: ни сборки, ни зависимостей, ни шрифтов из сети.
Файл открывается двойным кликом с диска ровно так же, как по ссылке.

Исключение - четыре из пяти 3D-моделей в `articles/tie-fighter/`: они подгружают библиотеку
рендеринга с CDN и без интернета не запускаются. Это не недосмотр, а часть результата теста,
и в статье об этом сказано отдельно.
